Workspace data-source scope (applies to every page)

States
selected = filled blue + check · unselected = outline, dim
hover · focus ring · last selected (disabled)
Each button shows how many hosts the source contributes, including when it is off. Phones keep the three buttons in one full-width row and drop the check box.
Rules
  • The scope filters every panel, chart, table, map and count on every page. Nothing ignores it.
  • At least one source stays selected; the last one cannot be turned off ("At least one source must stay selected.").
  • The selection lives in the URL as ?source=live,synthetic,replay, so links and reloads keep it.
  • Page facets (state, OS, agent) narrow within the scope and never widen it. The facet panel says so.
  • A page for a host whose source is off shows the "Source hidden by scope" state.
  • When a source is off, the page header says so ("REPLAY hidden").

Controls

One amber primary action per page. 2px blue focus ring with offset on every control. Selected nav is a raised fill with heavier weight. Destructive actions are secondary until confirmed in place.

Chart conventions

  • Measured: solid line. Forecast: dashed amber line and a dashed-edge band right of a NOW line.
  • Comparison period: dotted, 70%. Replay: fine dash. Threshold: dashed red with label.
  • Percent axes 0–100, or zoomed (80–100) with labelled ends. Gaps break the line.
  • Tooltip time matches the crosshair; it lists every series with source and value and never covers the crosshair.
  • Histograms scale to the data maximum. Predicted bars are outlined, never stacked.
  • Missing metric: "Not available" with a reason and no axes.

Table and widget conventions

  • Widgets are title-barred panels in a 12-column grid. Widgets in a row share a height; charts and histograms fill it.
  • KPI tiles: label, value, sub-line, then a sparkline below the text. Solid red or amber only for critical or warning.
  • Text left, numbers right in mono. State comes right after the host name so it is never clipped; low-priority columns (OS, host ID) go last and scroll or truncate.
  • Missing value is an en dash. Age is relative with exact time on hover. Default sort is state then name.
  • Names and headers never wrap; wide tables scroll inside their widget.

Shell and responsive behaviour

  • Desktop (above 900px): 216px sidebar with line icons; 46px top bar: breadcrumb, search, scope toggle, time range, alerts, user menu.
  • Tablet (700–900px): sidebar becomes a drawer opened by a menu button; the top bar wraps to rows: menu, breadcrumb and alerts; scope toggle full width; search full width; time range.
  • Phone (below 700px): widgets stack, KPI tiles two per row, tables scroll inside their widget, time-range buttons share the full width. The drawer overlays content with a scrim; tapping the scrim or the menu button closes it.
  • Time range and scope are global and live in the URL.

Voice and motion

  • Say what is known and its age: "Last report 14:09", never "recently". Say "Not available" with the reason, never an empty box.
  • Errors state the problem and the next step: "Could not load hosts. Retry."
  • Motion is functional: skeleton shimmer while loading and a short fade for tooltips; both off under reduced-motion. No entrance animation or pulsing status.
  • Icons: one 1.5px line set, drawn in SVG. No emoji.
